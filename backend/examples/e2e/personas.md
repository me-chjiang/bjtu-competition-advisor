# 端到端测试画像（虚构）

> AI 辅助生成的虚构人物，仅用于联调与体验测试，与真实个人无关。配合同目录 `competitions.json`（虚构竞赛目录，日期以 2026-10-30 为基准）使用。

每个画像给出「输入方式」和「期望」。测试者应像真实学生一样输入，不要迁就系统的特定句式。

## P1 粘贴简历（大一，AI 方向）

输入方式：第一条消息直接粘贴下面整段。

```
个人简介
陈思远，就读于示例理工大学计算机科学与技术专业（人工智能方向），目前大一。
技能：熟悉 Python，用 PyTorch 做过低光图像重建的科研实践；会一点 C/C++，高中参加过信息学社团；能在 Linux 上配置训练环境。
项目：
1. 低光图像重建轻量化模型（高中科研实践）：负责数据采集、训练学生模型、撰写实验分析。
2. 校园通知转日历小工具：React + TypeScript，支持导出 ICS。
获奖：2025 年青少年科技创新成果展示市级一等奖。
联系方式：13800000000，chensiyuan@example.com
希望：大一先积累竞赛经历，偏好 AI/视觉和算法类，个人或组队都行，每周大概能拿出 8 小时。
```

期望：一次整理出年级、专业、技能（带经历依据）、目标、每周 8 小时、组队偏好；`summary` 为分节 Markdown 且不含手机号和邮箱；AI 视觉、校内程序设计赛进入候选；能走到 R4 并得到可确认方案。

## P2 简短口语（大二，软件工程）

输入方式：多轮简短聊天。
1. 「大二软工的，想打算法比赛」
2. 被追问后：「会 Python 和 C++，力扣刷了两百多题」「一周六个小时吧」「自己一个人打」

期望：不要求固定句式；追问次数合理（≤3 轮）；团队赛不应被优先推荐或应提示组队要求。

## P3 中途更正与否定

输入方式：
1. 「我是大三的，数据科学专业，会 Python 和 SQL」
2. 「说错了，我其实大二」
3. 「我不想组队」
4. 「时间的话可能每周 10 小时左右，不太确定」

期望：年级更正为大二；组队偏好为个人；每周工时要么记为 10 并在 summary 注明不确定，要么保持未知并说明，二者都可接受，但不能卡住流程。

## P4 数学专业、工时未知

输入方式：「数学与应用数学大二，Matlab 和 Python 都用过一点，主要想参加数学建模，最好能组队。时间不确定。」

期望：工时保持未知也能完成画像确认和筛选；校内数模、统计建模进入候选；R4 方案 `feasibility=unknown` 时界面清楚说明为什么不能确认，以及怎么补工时（聊天或编辑画像）。

## P5 时间很紧

输入方式：「大三计算机，每周只有 2 小时，但想同时参加算法、数学建模和 AI 视觉三个比赛。」

期望：方案超出预算时提示不可行与原因；用户在 R4 聊天说「那只保留一个最重要的」后能重新生成并达到可确认状态。

## 边界检查（任一画像中穿插）

- 已关闭报名的「大学生数学竞赛（非数学类）」不能被保留为推荐。
- 「智能机器人挑战」「春季算法杯」日期未知，不能当作已确认日期。
- 刷新页面后能恢复到同一会话和阶段。
- 双击按钮不重复提交；处理中有明确的等待提示。
